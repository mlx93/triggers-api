## Quick Start Commands

```bash

git clone <repo-url>
cd zapier-triggers-api

# 2. Setup Python environment
python3 -m venv venv
source venv/bin/activate  # Mac/Linux
# venv\Scripts\activate  # Windows

# 3. Install dependencies (once requirements.txt exists)
pip install -r requirements.txt
pip install -r requirements-dev.txt

# 4. Configure AWS
aws configure

# 5. Verify SAM
sam --version
sam validate  # (once template.yaml exists)

# 6. Test local (once code exists)
sam local start-api
```

## Troubleshooting

**Common Issues:**

1. **SAM CLI not found:** Install via Homebrew (`brew install aws-sam-cli`) or pip (`pip install aws-sam-cli`)
2. **Docker not running:** Start Docker Desktop, verify `docker ps` works
3. **AWS credentials error:** Run `aws configure`, verify IAM user has correct permissions
4. **Python version mismatch:** Use `python3.12` explicitly, verify `python3 --version`
5. **Region not available:** Check AWS service availability by region
